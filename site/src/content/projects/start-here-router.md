Start Here converts vague browsing into explicit intent selection. Every card maps to a concrete next step, then logs intent for routing analysis.

## Build notes

- Four intent cards map to high-intent paths.
- Event tracking records card selection.
- Copy is short enough to scan on mobile.

## Outcome

Time-to-value dropped because users self-select context before reading details.
